# 1MM AI

Hovedproduktet ligger i [`1mm-ai/`](1mm-ai/) – et TypeScript-monorepo med web-app (Next.js), mobil-app (Expo/React Native) og delte pakker til AI, database og typer.

**Start her:** [1mm-ai/README.md](1mm-ai/README.md) indeholder komplette installations- og startinstruktioner.

Filerne i roden (`awakenx_agent.py`, `awakenx_api.py`, `index.html` m.fl.) er en tidligere Python-baseret prototype og er bevaret uændret.
